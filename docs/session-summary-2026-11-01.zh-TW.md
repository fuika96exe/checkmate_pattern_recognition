## 殺法規則的最終修改

### 悶殺與悶宮殺

- **悶殺**：終局必須將死；直線將軍時，垂直於將軍方向的宮內相鄰逃路至少有一格，而且全部被防守方自己的非士棋子堵住。馬將軍及已識別為重炮殺的局面不標為悶殺。非直線將軍仍使用現有的將軍子攻擊範圍外逃格檢查。
- 因此，直線將軍時，炮線上的士即使是炮架，也不會被誤當成垂直方向的堵路子。`LNl7XN` 現標為悶殺。
- **悶宮殺**：終局正在將軍的棋子種類只有炮；至少一門將軍炮以士為炮架，而且垂直於該炮線的宮內相鄰逃路至少有一格，並全部被防守方的士堵住。

### 花心殺與大膽穿心

- 原「花心兵」「花心車」合併為 **花心殺**（`CENTROID_CHECKMATE`）：終局攻擊方車或兵占據敵方花心 `e8`／`e1`，由其他棋子將死，花心子本身不能正在將軍。舊兩個 API 分類 ID 仍可作為查詢別名，返回合併後的結果。
- **大膽穿心**：過程中，攻擊方車或兵走入敵方花心並吃掉該格的士；吃士前防守方另有一士，或吃士後防守方有合法著法回吃該子。終局須將死。
- 保護判定使用吃士後的合法回吃，而非僅依吃士前的靜態攻擊關係。`ojl2M5`、`RV5wxE` 因不符合條件，已移除大膽穿心標籤。

### 馬類殺法

- **掛角馬**：修正題目以防守方失誤開局時，將後續應著索引錯置而漏標的問題。馬亦可早已在掛角位，終局實際控制一個敵將或宮內相鄰逃位，再由其他棋子將死；例如 `Lb0e1w`。保留既有跳入掛角位將軍的情形。
- **臥槽馬**：攻擊黑方時馬位為 `c8`／`g8`，攻擊紅方時為 `c1`／`g1`。終局該馬必須實際攻擊將帥或控制宮內相鄰逃格，並考慮蹩馬腿。`RWyWQP` 的馬被蹩腿且沒有實際控制，已移除臥槽馬標籤；`LxN1ej` 保留臥槽馬。
- **側面虎**：修正將敵將所在格無條件計入馬控制範圍的問題；棋譜中須有指定馬位的馬實際攻擊敵將的時刻，並保留既有肋道及非馬終局將軍要求。
- **雙馬飲泉**：已從可用分類、API 分類入口及前端選項移除。

### 其他殺法與優先級

- **進洞出洞**：修正題目以防守方先行時，將前面的失誤誤當作車將軍後應著的索引錯誤；`L3WgPJ` 現標為進洞出洞。
- **雙鬼拍門**：棋譜中須曾有兩枚攻擊方兵／卒同時占據敵方兩個象眼 `d8`／`f8` 或 `d1`／`f1`；終局須將死。雙車、車兵不再符合。
- **夾車炮**：參與的同側車和兩門炮須均位於敵方底部三橫線；紅方進攻黑方時為 `7/8/9`，黑方進攻紅方時為 `0/1/2`。仍保留原有同側及終局車炮將軍條件。這次沒有另加「三子必須共線、車必須在兩炮之間」的幾何規則。
- **太監追皇帝**：已從可用分類、API 分類入口及前端選項移除。
- 出現**花心殺、雙鬼拍門或平頂冠**時，不再同時顯示雙車錯；出現**臥槽馬**時不再顯示拔簧馬；**馬後炮與掛角馬**同時命中時只顯示馬後炮。
- 炮與車或兵同時將死，且還有其他殺法分類時，不再顯示雙將；沒有其他分類時仍保留雙將。其他棋種組成的雙將不因這條規則被排除。

## 子力組合兜底

只在終局**將死且沒有任何現有殺法分類**時啟用。困斃繼續使用困斃分類；無效題目不進行兜底。

1. 收集終局直接將軍子及控制敵將宮內相鄰可考慮逃格的攻擊方棋子。
2. 對沒有防守方棋子占據的逃格，模擬將帥移入及可能吃子後再判斷攻擊，以處理炮架變化、被吃棋子、蹩馬腿和將帥原位騰空。
3. 只按車、馬、炮、兵的**棋種**合併；同一棋種多枚只計一次。士、象、帥不納入組合名稱。
4. 精確匹配下表；不把四種棋種任意縮減為三種，也不額外產生其子集。未列出的組合保持未匹配。

| 單一棋種 | 多棋種 |
| --- | --- |
| 車殺、馬殺、炮殺、兵殺 | 車馬、車炮、車兵、車馬炮、車馬兵、車炮兵、馬炮、馬炮兵、馬兵、炮兵 |

API 的 `materialFallback` 與既有 `matches` 分開；題庫索引使用 `materialId`。例如 `o74w5P` 為車炮：黑車 `f0` 將軍，黑炮 `g1` 控制 `d1` 逃格。

## 已討論但尚未針對問題修改的規則

- `Lp10nd`：曾詢問為何不是鐵門栓。現行鐵門栓規則要求中路有防守方的士形成門栓；該題未滿足程序條件。本次沒有因此另改鐵門栓定義。
- `oyMnl7`、`qYgWGP`：終局由馬直接將死，現行側面虎還要求非馬棋子同時將軍，所以未標側面虎。`LxN1kM` 的指定位置馬控制逃格，但棋譜中沒有實際攻擊敵將，也未標側面虎。本次沒有為這三題加特例。
- `oM0bAY`：現行非直線兵將的悶殺檢查把將軍兵所在格也當成需要防守方棋子堵住的逃格，導致未標悶殺；本次只解釋，沒有針對此題修改。它其後可獲子力組合兜底標籤。
- `RdpM42`：兩炮雖同列，但實際將軍炮的炮架是士，另一炮在將軍炮後方；現行重炮規則要求一炮以另一炮作炮架，因此未標重炮。此題沒有單獨修改，之後可獲子力組合兜底標籤。
- 夾車炮曾討論加入「車被兩炮真正夾住」及實際參與的檢查；最終已實施的是上述敵方底部三橫線限制，**沒有**實施共線夾持判斷。
