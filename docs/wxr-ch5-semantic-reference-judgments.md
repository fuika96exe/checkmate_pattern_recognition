# WXR CH5：110 题棋规语义参考判例

这是给规则实现／另一个 AI 使用的**棋规语义基准**，不是当前工作区某一次程序回放的原始输出。结论来自已逐题核对的 `ch5_cases.json`，并纳入本对话确认的补充规则。

## 统一规则

- 优先级：**长将 > 捉被卧槽马牵制的车 > 普通有效长捉 > 闲**。
- 普通捉必须是有效的、重新建立的攻击关系；持续不变的静态攻击不重复计数。
- 受保护目标须按合法回吃及交换价值判断；牵制而不能合法回吃的保护是假保护。低价值子捉车，即使被回吃，仍可能有效。
- 将帅、过河兵卒可长捉；未过河兵卒作为被捉目标不构成长捉责任。
- 一子分捉多个不同目标允许；多个棋子轮流捉同一物理棋子不允许。
- 卧槽马本身牵制车允许；只有**另一枚同方棋子**有效捉该受牵制车，才升级为第二优先级。
- `d025、d052、d076、d098` 虽在当前 JSON 的原始走子中未达到自动重复次数，但本基准按题目提供的循环性质直接裁定。

术语：**红变**＝红方必须变着，**黑变**＝黑方必须变着，**和**＝双方无唯一违规责任方。

## 给实现者的检查清单

1. 先用“局面＋轮到谁走”识别循环；对测试语料可另设 `force_adjudicate_provided_cycle`，以验证不完整线路的棋例性质。
2. 每手保存稳定棋子 ID 的 `attacker -> victim` 关系，不能只按格子或翻译后的着法文字比较。
3. 仅在关系中断后再次建立时记录“捉”；攻击关系未改变时不能重复计数。
4. 循环分类不能只看“本手是否有攻击”，而要检查循环内的共同物理目标、攻击者数量和例外规则。
5. 对 d039–d041，固定卧槽马点为红 `C8/G8`、黑 `C1/G1`；马腿位的敌车只有在“除吃马外无合法车着”时才算受牵制。
