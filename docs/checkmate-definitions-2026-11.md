# 杀法识别定义（2026-11）

- 闷杀：终局将死，直线将军时，垂直于将军方向的宫内相邻去路至少有一格，且全部由防守方非士棋子占据。马将军及重炮杀不计入闷杀。
- 挂角马：马可早已占据挂角位，终局实际控制一个将帅或宫内去路，并由其他棋子将死；亦保留跳入挂角位将军的情形。
- 卧槽马：终局卧槽位的攻击方马必须实际攻击敌将，或控制其宫内相邻逃路；判断时考虑蹩马腿。
- 花心杀：终局攻击方车或兵位于敌方花心 e8/e1，且该子没有将军，由其他棋子将死。统一编号为 `CENTROID_CHECKMATE`；旧 API 编号仍可查询同一规则。
- 大胆穿心：棋谱中攻击方车或兵吃入花心的敌士；吃入前对方另有一士，或吃士后防守方有合法着法可以回吃该子。终局须将死。
- 闷宫杀：终局将军子种类只有炮，至少一门将军炮以士为炮架，且垂直该炮线的宫内相邻去路至少有一格，并全部被防守方的士占据。
- 侧面虎：保留原有马位、肋道及其他棋子将军要求，且棋谱中必须有侧面虎马实际攻击敌将的时刻；计算时考虑蹩马腿。
- 双鬼拍门：棋谱中的某个局面，攻击方两枚兵同时占据防守方两个象眼 d8/f8 或 d1/f1；终局须将死。
- 夹车炮：参与的车及两门炮均在防守方底部三横线（红方进攻 7/8/9，黑方进攻 0/1/2），并符合现行同侧和终局将军条件。
- 双将：炮与车或兵同时将死时，若同时命中其他杀法，则不显示双将标签；若没有其他分类，仍保留双将。
- 标签互斥：花心杀、双鬼拍门或平顶冠与双车错同时命中时，只保留前者；卧槽马与拔簧马同时命中时，只保留卧槽马；马后炮与挂角马同时命中时，只保留马后炮。
- 子力组合兜底：终局将死且没有命中杀法时，合并直接将军子与控制可考虑的宫内相邻逃格的攻击方车、马、炮、兵种类；士、象、帅不计入组合。对每个没有防守方棋子占据的逃格模拟将帅移动及吃子，再计算攻击，处理炮架和蹩马腿。同种子力只计一次；仅单一棋种时标为车杀、马杀、炮杀或兵杀，也接受车马、车炮、车兵、车马炮、车马兵、车炮兵、马炮、马炮兵、马兵、炮兵的精确组合。其他组合、非将死及已有杀法的局面不启用兜底。

静态 FEN 的行棋方必须为被将死的一方。棋谱判断会同时检查起始局面与各步后局面；没有提供历史时，不能推断此前发生过的吃士或占位。
