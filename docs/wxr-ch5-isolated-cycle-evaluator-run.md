## 判别依据

1. **局面与棋子身份**：每一步保留棋子的稳定 ID；循环判断看“盘面＋轮到谁走”，长捉判断看同一攻击者／被攻击者实体，不能只看所在格。
2. **关系重新建立**：攻击关系持续存在时不反复记捉。攻击者、被攻击者或炮架／屏风变化使关系消失后，后续同向关系重新建立，才记为新的捉。
3. **有效捉**：模拟立即合法吃子与对方立即合法回吃。被牵制、会露将而不能回吃的保护是假保护；低价值子吃高价值子（如炮／马捉车）即使会被回吃，仍可获利而算有效捉；同价值可直接吃回通常是献／兑子，不算捉。
4. **兵卒和将帅例外**：将帅、过河兵卒可以长捉；未过河兵卒不作为违规长捉目标。
5. **多个目标**：同一攻击者轮流捉不同被攻击者为允许的一子分捉；多个攻击者轮流捉同一物理目标为禁止的多子捉一子。
6. **卧槽马牵制车**：仅在红马位于 `C8/G8` 或黑马位于 `C1/G1` 时检查。敌车必须处于马腿格、并且除吃该马外没有合法车着。牵制本身允许；同方另一枚棋子有效捉该车时，才标为“捉被卧槽马牵制的车”。
7. **优先级**：长将（3） > 捉被卧槽马牵制的车（2） > 普通有效长捉（1） > 闲（0）。等级较高的一方必须变着；同级判和。
